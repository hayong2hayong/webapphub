# 교실 도구함

Google 홈페이지의 여백·중앙 검색·다색 포인트를 참고한 정적 웹앱 허브입니다. **무작위 번호 뽑기**와 **자리 배정**을 제공합니다. 허브와 두 도구는 브라우저에서 동작하며 회원가입·서버·인증키가 필요 없습니다. 급식·시간표 앱과 외부 데이터 조회 연결은 제거했습니다.

## 실행과 검증

Node.js 22 이상에서 프로젝트 폴더를 열고 실행하세요. 패키지 설치는 필요 없습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. ES 모듈과 루트 경로를 사용하므로 HTML 파일을 더블클릭하는 방식은 지원하지 않습니다.

```sh
npm test
npm run build
```

`npm`이 없는 환경에서는 각각 `node scripts/serve.mjs`, `node --test`, `node scripts/build.mjs`를 직접 실행해도 같습니다.

빌드는 `dist/`의 정적 자원을 검사합니다. 서버 번들이나 별도 배포 폴더를 만들지 않습니다. 정적 호스팅에는 `dist/`의 공개 파일을 제공합니다. 현재 공개 Sites 주소를 유지하며, 이 저장소에는 Firebase 프로젝트·함수·데이터베이스·외부 API 설정이 없습니다.

## 할 수 있는 일

- 도구 검색·분류·즐겨찾기
- 개인 앱 링크 추가·수정·삭제(최대 100개)
- 개인 앱·즐겨찾기 JSON 백업·복원(최대 512KB, 복원 전 교체 확인)
- 번호 1~999, 제외 번호, 한 번에 최대 100개 추첨
- 한 회차 안에서는 항상 중복 없이 추첨. ‘이미 뽑은 번호 제외하기’를 켜면 회차 사이에도 중복 방지
- 큰 결과 화면·전체 화면·최근 20회 기록
- 자리 배정: 짝꿍 두 자리씩 3분단·5행, 최대 30명, 제외 번호·고정석·빈자리 지정
- 고정석과 지정한 빈자리를 유지하며 나머지 번호를 무작위 배정, 다시 섞기, 배정표 인쇄/PDF 저장

## 자리 배정 사용하기

1. 허브에서 ‘자리 배정’을 엽니다. 짝꿍 두 자리씩 3분단, 5행의 30석입니다.
2. 학생 수(최대 30명)와 제외 번호를 정합니다.
3. 자리 편집에서 좌석을 클릭하여 자동 배정·빈자리·번호 고정을 선택합니다. 고정석은 다시 섞어도 유지되며, 지정 빈자리에는 배정하지 않습니다.
4. 배정하기를 누르면 나머지 번호를 중복 없이 배정합니다. 조건을 바꾸면 새로 배정해야 인쇄할 수 있습니다. 마지막 성공 결과는 결과 보기에서 확인할 수 있습니다. 학생 수·제외 번호를 바꿀 때 고정번호와 충돌하면 안내에 따라 고정을 해제하거나 조건을 수정하세요.
5. 인쇄 버튼에서 종이로 인쇄하거나 브라우저의 PDF 저장을 선택합니다. 결과는 현재 탭에서만 유지되며 새로고침하면 사라집니다.

## 개인 목록과 공개 목록

**앱 추가 버튼**은 현재 브라우저에만 링크를 저장합니다. 다른 방문자에게 공개되거나 기기 간 자동 동기화되지 않습니다. 브라우저 데이터를 지우면 개인 목록도 사라지므로 중요한 목록은 백업하세요. 저장이 차단되면 현재 탭에서는 계속 사용할 수 있고 경고를 표시합니다. 도메인이 바뀌면 기존 사이트에서 JSON 내보내기 후 새 사이트에서 가져와야 합니다.

**모든 방문자에게 보이는 공개 앱**을 추가하려면 `dist/lib/catalog.mjs`의 `catalog` 배열을 수정한 후 재배포합니다. 기존 id는 유지하고 새 id는 고유하게 만드세요.

```js
{
  id: 'new-classroom-tool',
  title: '새 수업 도구',
  description: '도구가 하는 일을 한 줄로 적어 주세요.',
  category: '수업 도구',
  url: '/apps/new-classroom-tool/',
  icon: 'book',
  builtin: true
}
```

내장 앱은 `dist/apps/new-classroom-tool/index.html`에 만드세요. 외부 공개 앱 링크라면 HTTPS 주소를 쓰고 `builtin: false`로 지정합니다. 공개 목록의 항목은 URL 종류에 관계없이 개인 편집/삭제 대상이 아닙니다. 제공 아이콘은 `grid`, `dice`, `folder`, `book`, `star` 등이며 `dist/lib/ui.mjs`에서 확인할 수 있습니다.

현재 분류는 수업 도구 / 교과 학습 / 학급 운영 / 창작 활동 / 종합 허브입니다. 공개 앱 id를 삭제할 때는 과거 즐겨찾기 백업과의 호환성을 함께 검토하세요.

이전 저장 자료나 백업에 남아 있는 급식·시간표 기본 도구의 즐겨찾기는 복원할 때 제외합니다. 개인 앱과 다른 즐겨찾기는 유지하며, 같은 id를 가진 개인 앱도 보존합니다.

## 구조

```text
dist/
  index.html, styles.css, hub.mjs   허브
  lib/catalog.mjs                  공개 도구 목록
  lib/core.mjs                     추첨·입력·백업 검증
  lib/hub-state.mjs                개인 목록·즐겨찾기 저장과 복원
  lib/ui.mjs                       공통 화면 도우미
  apps/number-picker/              무작위 번호 뽑기
  apps/seating-chart/              짝꿍 3분단 자리 배정
scripts/serve.mjs                  로컬 정적 서버
scripts/build.mjs                  공개 정적 자원 검사
tests/                            핵심·저장·자리 배정 회귀 테스트
docs/                             현재 명세·검증 이력
```

## 저장·사용 범위

학생 이름·명단·성적을 입력하지 않습니다. 번호 추첨 기록과 자리 배정 결과는 메모리에만 있으며 새로고침·초기화 시 지워집니다. 설정 중 번호 범위·제외 번호·중복 옵션을 바꾸면 다음 추첨 때 새 세션이 시작됩니다. 한 번에 뽑을 개수만 바꾸면 기존 회차를 이어갑니다. 외부 추적 스크립트와 외부 폰트는 없습니다. 개인 링크를 열면 해당 서비스의 정책이 적용됩니다.

이 앱은 수업용 간단한 무작위 선택 도구이며 감사 가능한 공식 추첨 시스템은 아닙니다. 완전한 오프라인 재방문, 계정, 다중 기기 자동 동기화는 구현하지 않았습니다.

`docs/superpowers/`의 급식·시간표 및 Firebase 이전 문서는 폐기된 구현의 역사 기록입니다. 현재 실행·배포 지침으로 사용하지 않습니다. 외부 등록·운영 처리 결과는 별도 운영 기록에서 확인합니다.
