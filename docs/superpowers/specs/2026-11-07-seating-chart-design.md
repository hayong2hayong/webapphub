# 자리 배정 앱 — 짧은 설계안

상태: 2026-11-07 사용자 수정 요청 반영 — 짝꿍 3분단·5행·최대30명, 고정석 및 빈자리 지정. 기존 공개 허브의 두 번째 내장 앱으로 추가한다.

목적: 교사가 번호를 기준으로 교실 자리를 무작위로 정하고 화면과 인쇄물로 확인한다.

## 방식
짝꿍 두 자리씩 묶은 3분단을 통로로 구분하고 5행으로 표시한다(30석). 칠판은 위쪽. 임의의 행·열 설정을 없애고 실제 교실에서 흔히 쓰는 배치를 바로 보여 준다. 기존 HTML/CSS/JS와 Google 참고 디자인을 이어 쓴다.

## 첫 버전
- 학생 수(1~30명, 번호 1~학생 수)·제외 번호 입력. 기본30명. 3분단×짝꿍2자리×5행 고정 배치.
- 자리 편집에서 좌석을 누르면 대화상자로 ‘자동 배정 / 빈자리 / 번호 고정’을 선택한다. 키보드와 명시적 레이블·초점 복귀를 제공한다.
- 고정석은 번호와 ‘고정’ 표시를 보여 주고 다시 섞기에서도 같은 자리를 유지한다. 고정번호는 다른 자리에 중복 등장하지 않는다.
- 지정한 빈자리는 배정에서 제외하고 계속 빈자리로 표시한다. 인원이30명보다 적어서 자동으로 남는 자리도 빈자리로 표시하되 지정빈자리와 구분한다.
- 고정석·지정빈자리 외의 자리에 남은 번호와 남는 빈자리를 무작위로 섞는다. 제외된 번호는 등장하지 않는다.
- 고정번호 중복, 빈자리/고정석 겹침, 제외번호/고정번호 충돌, 범위 밖 고정번호, 좌석 부족·잘못된 입력은 설명하고 이전 정상 배정은 유지한다. 설정 수정은 다음 배정에 적용하며 지난 결과임을 명시한다.
- 다시 섞기, 초기화, 현재 배정 인쇄 제공. 배정 전과 설정 변경 후 미적용 상태에서는 인쇄하지 않고 먼저 배정을 안내한다.
- 결과는 현재 탭에서만 유지하고 새로고침 시 초기화한다. 학생 이름·명단·서버·DB·추가 로그인 없음.
- 허브에 ‘자리 배정’ 카드와 빠른 실행을 추가. 기존 저장된 앱 목록·즐겨찾기·백업은 유지한다.

경로: `/apps/seating-chart/`, 공개 id: `seating-chart`, 분류: 학급 운영.

## 검증과 공개
고정석 보존·중복/충돌·좌석 부족·모두 제외·빈자리·입력 경계·입력 불변을 Node 테스트로 검증한다. 브라우저에서 3분단 배치, 자리 설정, 재배정 고정 유지, 오류 시 이전 결과 보존, 키보드·모바일·인쇄용 스타일을 확인한다. 기존 Site의 audience·id로 갱신 배포하며 별자리 등록을 중복 신청하지 않는다.
