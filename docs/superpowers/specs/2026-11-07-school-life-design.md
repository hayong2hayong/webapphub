# 한솔고 급식·시간표

> **역사 기록 · 폐기됨 (2026-11-07):** 사용자 요청으로 급식·시간표 앱과 외부 API·백엔드 연결을 제거했다. 이 문서는 당시 설계를 보존하며 현재 구현·배포 지침으로 사용하지 않는다. 현재 범위는 [개발명세서](../../SPEC.md)를 따른다.

2026-11-07 사용자 결정: 반장에게 배포하는 공용 앱. 학생은 키·로그인 없이 사용. 나이스 인증키는 서버 비밀 설정에 한 번 등록한다. 대상은 세종 한솔고등학교 2학년8반이다.

## 화면과 동작
- 기존 허브에 ‘급식·시간표’ 내장 앱 카드, `/apps/school-life/`.
- 학교·학급을 상단에 표시. 한국 시간 기준 오늘 날짜, 이전/다음 날짜와 오늘로 이동.
- 선택한 날짜의 조식·중식·석식을 등록된 범위에서 표시. 메뉴의 알레르기 번호는 원본 그대로 보존하고 임의로 안전성을 판단하지 않는다.
- 해당 주 월~금 시간표를 교시별로 표시. 여러 과목/계열/강의실이 같은 교시에 있으면 덮어쓰지 않고 함께 표시한다.
- 학교에서 미등록/주말·방학 등 ‘자료 없음’, 통신 실패, 일부 자료 실패를 구별한다. 날짜를 빠르게 바꾸면 늦은 이전 응답이 새 화면을 덮지 못하게 한다.
- 한솔고2학년8반 고정 공용 링크이며 학생 이름·명단·개인 로그인·개별 인증키 입력 없음.

## 서버
- `GET /api/school-week?date=YYYY-MM-DD`. 입력 날짜가 속한 월~일 데이터를 반환한다. 다른 학교나 임의 upstream URL을 받지 않는다.
- 학교 코드: 교육청 I10 / 학교9300058, 공개 학교 검색으로 확인. 시간표 hisTimetable, GRADE2/CLASS_NM8. 급식 mealServiceDietInfo.
- NEIS_API_KEY는 Sites secret. 로컬 등록용 .env.local은 Git 제외 확인, 읽을 때 출력하지 않고 서버 비밀 설정으로 옮긴 후 로컬 원문 삭제. 키를 소스·일반 백업·응답·로그·브라우저에 넣지 않는다.
- 공식 키 없는5건 샘플은 운영 데이터로 제공하지 않는다. 키 없으면 준비 상태를 명확히 표시한다.
- 달력 날짜 검증, 서버상 현재 연도±1 범위, 고정 학교/학급, HTTPS 공식 NEIS만 호출, 시간제한·안전한 오류 문구. 한 주로 정규화한 캐시(5분)로 동일 조회를 합친다.
- 정적 파일은 기존 경로를 유지하면서 Worker 모듈 안에 빌드 시 포함한다. 별도 패키지 설치·DB 필요 없음. 기존 번호 뽑기와 자리 배정의 동작·공개 주소 유지.

## 인수 기준
- 학생은 공개 URL에서 인증 없이 실제 급식·시간표 조회 가능. 키는 개발자 도구에 노출되지 않는다.
- 전체 나이스 결과를 페이지 수에 맞게 가져오고, 샘플처럼 일부5교시를 완전한 시간표로 표시하지 않는다.
- 한국 날짜와 주 경계, 학급 필터, 원본 메뉴, 복수 과목, 자료 없음/오류, 입력값, 키 누출 방지·캐시를 테스트한다.
- 기존23개 테스트 및 기존 두 앱 공개 경로를 유지한다. 독립 검토·브라우저 QA 후 같은 Site 갱신 배포.
